# robots-check

Robots.txt validator and analyzer. Checks syntax, finds blocking rules, reports sitemaps.

Built by [Victor Valentine Romo](https://victorvalentineromo.com) at [Scale With Search](https://scalewithsearch.com).

## Usage

```bash
robots-check https://example.com
```

## Install

```bash
curl -o ~/.local/bin/robots-check https://raw.githubusercontent.com/b2bvic/robots-check/main/robots-check
chmod +x ~/.local/bin/robots-check
```
